# 官方文档核对记录

核对日期：2026-10-24。以下支持平台能力与配置思路，不能证明本项目已在账号中完成搭建。

- [工作流介绍](https://docs.coze.cn/guides_workflow)：工作流编排及变量类型。
- [代码节点](https://docs.coze.cn/guides_code_node)：Python入口、标准库与端口类型。每份节点仅一个main，避免不支持的额外函数定义。
- [知识库检索](https://docs.coze.cn/guides_knowledge_node)：显式检索节点与召回配置。实际正文输出键仍要看账号试运行。
- [大模型节点](https://docs.coze.cn/guides_llm_node)：提示词变量、文本输出、模型按账号可用范围选择。
- [变量聚合](https://docs.coze.cn/guides_variable_merge_node)：互斥分支选第一个非空值，输出通常为Group1、Group2等固定名称。
- [批处理节点](https://docs.coze.cn/guides_batch_node)：批处理输入数组、体内调用与数组输出；并发及次数需明确设置。
- [导入导出](https://docs.coze.cn/guides_import_and_export_workflow)：导入使用平台DSL ZIP，当前文档说明需要付费套餐；本包不伪装成官方导出ZIP，也不要求购买套餐。

本文仅记录必要结论，未复制整页平台说明。平台界面和套餐会变化，实际资源权限以账号页面为准。
